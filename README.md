# Data Analyst Portfolio

A collection of data analysis projects.

## Projects

- [Customer Churn Analysis](customer-churn-analysis/) — Exploratory data analysis of telecom customer churn using
  Python, Pandas, and data visualization to identify at-risk customer segments and drive retention strategy.
- [SQL Sales & Business Analytics](sql-sales-analysis/) — Answering business questions (revenue, top customers,
  product performance, sales-rep performance) with SQL joins, CTEs, and window functions.
- [Sales Performance Dashboard (Power BI)](power-bi-sales-dashboard/) — Star-schema data model, DAX measures, and
  a 4-page interactive dashboard covering revenue, customers, products, and sales-rep performance.
- Real Estate Price Prediction — data cleaning in a machine learning and data science project.
